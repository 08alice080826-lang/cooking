recipes

人気レシピ

基本のミルクプリン

調理時間 25分 / 冷却 2時間

材料（4個分）

牛乳 400ml / 砂糖 40g / ゼラチン 6g / バニラ少々

  1. 牛乳の半量を鍋で温め、砂糖を溶かす。
  2. ふやかしたゼラチンを加え、完全に溶かす。
  3. 残りの牛乳とバニラを混ぜ、器に流す。
  4. 冷蔵庫で2時間以上冷やして完成。

しっとりガトーショコラ

調理時間 50分

材料（15cm丸型）

チョコ 100g / 無塩バター 70g / 卵 2個 / 薄力粉 20g

  1. チョコとバターを湯せんで溶かす。
  2. 卵黄、粉類を順に混ぜる。
  3. メレンゲを2回に分けて合わせる。
  4. 170℃で30〜35分焼き、余熱で落ち着かせる。

いちごのショートケーキ

調理時間 70分

材料（12cm）

卵 2個 / 砂糖 60g / 薄力粉 60g / 生クリーム 200ml / いちご

  1. 共立てした生地を170℃で約25分焼く。
  2. 完全に冷まして3枚にスライスする。
  3. シロップ、クリーム、いちごを重ねる。
  4. 全体をナッペしてデコレーションする。
